Projects

Each project targets one device first, but all of them are written to be ported. Here is what each one runs on, what works, and where to find the source.

HackiOS

By the OOSEX GANG team, open-sourced in October 2026 in two repositories: the kernel side (XNU changes, the EFI loader, the UEFI port, Wi-Fi) and the userland side (the system image builder, their init, the GPU and audio pieces).

Works

  • Lock screen, home screen, gestures, Control Center, widgets
  • Settings, Clock, Calendar, Photos, Notes, Safari and more
  • Touchscreen with multitouch, power and volume keys
  • All 8 cores; about 20 seconds to the lock screen
  • Adreno 642L GPU drawing the interface
  • Wi-Fi: join a network in Settings, browse in Safari
  • Speakers, microphone, front and rear camera in Camera.app
  • Sileo and Procursus (apt, tweaks, SSH)

Missing

  • Cellular and Bluetooth
  • Charging while iOS runs (the battery only drains)
  • Metal for apps (Apple's system shaders are being brought up one by one)
  • App Store downloads and Apple ID sign-in
  • Video recording

It's set up as a research bench: each session runs for a set time, then the kernel hands its log back to the loader. Start with the kernel repository's README.

ios-sweet

A port of XNU to the Redmi Note 10 Pro with its own boot shim and drivers.

Works

  • Lock screen and home screen (about 4 minutes on the Apple logo)
  • Touchscreen, swipe-up to go home, app switcher
  • Power and volume buttons, screen lock and wake
  • Settings, Control Center, notification center
  • The App Store opens (installing apps is untested, since there is no internet yet)
  • All 8 CPU cores, read/write storage

Missing

  • Wi-Fi, Bluetooth, mobile network
  • Audio, camera, sensors, GPS, Face ID
  • GPU: the CPU draws everything
  • Real battery level (it always shows 100 %)

Build and install steps are in the README.

UniXNU

An independent project that runs iPadOS 17 on the Xiaomi Pad 6S Pro (sheng, Snapdragon 8 Gen 2), using the iPadOS firmware of the 2017 iPad Pro. Like HackiOS it boots through a ported Mu-Silicium UEFI, with its own UEFI boot manager and loader (DarwinBoot). The kernel is patched to run with 4 KB memory pages, and the drivers are split into separate repositories under the UniXNU organization.

Works

  • iPadOS home screen and Settings
  • GPU: a native kernel driver for the Adreno 740, with Metal translated to Vulkan for Mesa's Turnip driver; the system interface is composited on the GPU
  • Touchscreen, display, UFS storage

Missing

  • Wi-Fi, Bluetooth, USB, audio, camera, sensors
  • Battery driver, sleep and wake

Documentation, including a porting guide, is at unixnu.com. Source: UniXNU and the sheng device repository.
