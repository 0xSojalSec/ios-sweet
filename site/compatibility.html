Will it work on my phone?

Only one phone runs it today: the Redmi Note 10 Pro (sweet). Every other phone needs a port. How much work that port is depends almost entirely on the chip inside, so this page groups phones by chip family instead of listing models.

The basics your phone needs

  • An unlockable bootloader that supports fastboot boot (booting an image from the PC without flashing it). Xiaomi, Poco, OnePlus, Pixel and most Motorola phones can do this. Samsung phones use Odin instead of fastboot, and Huawei bootloaders can't be unlocked anymore.
  • A 64-bit ARM chip. Every phone from the last eight or so years has one.
  • UFS storage. ios-sweet has a UFS driver. Phones with eMMC storage (common in budget models) need a new storage driver first.
  • 4 GB of RAM or more. The iPhone X has 3 GB, and the kernel can't use all of the phone's memory because Qualcomm reserves parts of it.
  • A screen the bootloader leaves on. ios-sweet draws into the image buffer the bootloader uses for its logo. Almost all Qualcomm phones do this.

Chip families

ChipChanceWhat a port involves
Snapdragon 730 / 730G / 732G (SM7150)
e.g. Poco X3 NFC, Poco X3, Redmi Note 10 Pro Max, Mi 9T, Mi Note 10, Pixel 4a		 Best Same chip as the Redmi Note 10 Pro, so the kernel side mostly works as is. You change the board details: screen size, touch controller, button wiring, memory layout. If the phone uses a different touch chip, that driver needs a new protocol.
Snapdragon from 2018 on
845, 855, 865, 870, 888, 8 Gen 1/2/3, 7xx, 690, 750G and most newer chips with UFS		 Good Same building blocks as the 732G: the same interrupt controller type, the same kind of power controller (RPMh) and the same serial engines for I²C. Mostly the addresses differ, so a port means updating a few config values (memory map, storage, screen) and pointing the touch and button drivers at your phone's hardware. Some cheaper chips of this era (the 662 and 665, for example) still use the older RPM power controller, see the next row. The newest chips (8 Gen 1 and later) change a few blocks, like a newer PMIC bus, and need more work.
Older Snapdragon
820/821, 835, 625, 636, 660 and similar		 Hard These use an older power controller (RPM instead of RPMh) and an older I²C block, so the touch power and touch drivers have to be rewritten. Many of them have eMMC storage. Their CPU cores are an older ARM generation than the iPhone X's chip, and nobody has tested whether iOS 16 runs well on them.
Snapdragon with eMMC
many 4xx and some 6xx phones		 Hard Everything in the row above that matches your chip, plus a new eMMC (SDHCI) storage driver, since iOS has to live somewhere.
Google Tensor (Pixel 6 and later) Separate port The bootloader is friendly, but the chip is Google's own design, built on Samsung's platform up to Tensor G4, and shares almost nothing with Snapdragon. The shim and every driver would be new. Ports for these are separate projects.
MediaTek (Helio, Dimensity) Probably not Different hardware from the ground up, bootloaders that are often hard to unlock, and vendor kernel sources that are harder to learn from. It's not impossible, but it would be a new project rather than a port.
Exynos, Unisoc, Kirin Probably not Same story as MediaTek. On top of that, Samsung phones have no fastboot boot and Huawei bootloaders can't be unlocked.

Quick answers

Poco X3 NFC? It has the same chip.

Most likely yes. It's the easiest port there is: same SoC, different board. See Port it to your phone.

My phone is MediaTek (Redmi Note 9, many Redmi and Realme models).

Probably not. Look up the exact chip first: some phones sold under the same name come in both a MediaTek and a Snapdragon version.

Can I run iPadOS on my Android tablet?

Not with this project. iPadOS comes from a different firmware and expects iPad hardware. The same approach could work in theory, but nobody has done it.

Can it run iOS 17, 18 or newer?

Not on this path. Every iPhone that runs iOS 17 or newer is built for pointer authentication (arm64e). The Snapdragon 732G in this phone, like most ARMv8.2 chips, doesn't have it, so this path stops at iOS 16 on the iPhone X. (Why an iPhone X?)

How do I find out which chip I have?

Search your model on GSMArena and look at the "Chipset" line, or install an app like CPU-Z. The storage type (UFS or eMMC) is listed there too.
