Future plans

No dates and no promises. This is a hobby project, and every new piece of hardware means writing a driver from scratch. Here's what's being looked at.

Wi-Fi and Bluetooth

The phone has a Qualcomm Wi-Fi and Bluetooth chip, and it's a lot more involved than the touchscreen was. Before the chip does anything, its firmware has to be loaded and it has to be brought up through Qualcomm's remote processor interface. After that, iOS needs to see it as a network interface its own Wi-Fi stack can drive, and Bluetooth needs something that looks like Apple's Bluetooth controller.

A first step toward networking is already in the kernel: the phone can act as a USB network device, so the PC can ping it. Getting iOS itself to use that connection for the internet is still being worked on.

GPU acceleration (maybe)

Right now the CPU draws every frame, which is why animations stutter. iOS draws through Apple's Metal interface, so a GPU driver would have to accept Metal work and turn it into commands for the Adreno 618. Nobody has done that for an Adreno GPU under iOS, and Apple doesn't document how its GPU drivers talk to the system.

It might be possible. Open-source drivers for Adreno exist on Linux (freedreno), so the hardware side is fairly well understood. Still, this is the hardest item on the list by far. If it ever happens, it will take a long time.

More phones

That part is up to you. Ports to other Snapdragon phones are the fastest way for this to grow. Start with the porting guide and share your progress on r/hackios.

Follow along

The commit history on GitHub is the most up-to-date status. Every kernel change is a numbered patch, and NOTES.md logs each boot attempt, including the ones that failed.
