Real iOS on an Android phone

ios-sweet boots Apple's iOS 16.7.16 on a Redmi Note 10 Pro (Snapdragon 732G). It is the real thing: Apple's kernel built from its open-source code, and the system files of an iPhone X, with a handful of settings changed so it boots on foreign hardware. There is no emulator or launcher involved, and no Android running underneath.

This is a research project, not a daily driver. There is no Wi-Fi, no calls, no internet yet, and the security features are switched off. Installing it wipes the phone's user data partition, so everything on your Android install is gone.

Where it is right now

Works

  • Boots to the lock screen and home screen (about 4 minutes on the Apple logo)
  • Touchscreen, swipe-up to go home, app switcher
  • Power and volume buttons, screen lock and wake
  • Settings, Control Center, notification center
  • The App Store opens (installing apps is untested, since there is no internet yet)
  • All 8 CPU cores
  • Reads and writes its own storage

Missing

  • Wi-Fi, Bluetooth, mobile network
  • Audio, camera, sensors, GPS, Face ID
  • GPU: the CPU draws everything, at about 20 to 30 fps
  • Real battery level (it always shows 100 %)

Have a Redmi Note 10 Pro?

Then you don't need to port anything. The full build and install steps are in the README on GitHub. You need an unlocked bootloader, a Linux PC and a GitHub account (the kernel builds on GitHub's free macOS runners).

Questions, ports and progress reports go to r/hackios.
